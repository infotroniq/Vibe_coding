03 / TOUT SIMPLEMENT

Vos questions.
Nos réponses.

Un projet commence aussi
par les bonnes questions.

Quel est le budget pour un site web ?

Chaque projet est différent. Après un échange sur vos besoins, nous vous proposons un devis personnalisé précisant le périmètre, le calendrier et le budget.

Mon site sera-t-il adapté aux mobiles ?

Oui. La mise en page s’adapte aux téléphones, aux tablettes et aux ordinateurs pour offrir une navigation confortable sur chaque écran.

Pouvez-vous m’aider avec mon nom de domaine ?

Oui. Nous vous accompagnons dans le choix et la configuration de votre domaine, ou dans le transfert d’un domaine existant. La disponibilité doit être vérifiée auprès d’un bureau d’enregistrement.

Comment se déroule le lancement d’un projet ?

Nous échangeons d’abord sur votre activité et vos attentes. Nous définissons ensuite les contenus, les fonctionnalités et les étapes du projet avant de commencer la création.
